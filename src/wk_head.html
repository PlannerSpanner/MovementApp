Strength

Every session:
  • Stop 3–4 reps short of failure — if the last rep slowed down, the set ended one rep ago.
  • Move submaximal weight with intent. Never grind.
  • Rest 90 sec–2 min between sets.
  • Add load only when a session feels genuinely easy — roughly every 2–3 weeks.
  • All pressing neutral-grip and floor-limited (AC joint).
  • All pulling neutral or pronated grip — supinated loads the healing bicep tendon.
